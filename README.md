# 🎬 Movie Management System — MERN + HTML/CSS

The **Movie Management System** is a full-stack web application built using the **MERN stack** along with **HTML and CSS**, designed to manage movie records with full CRUD (Create, Read, Update, Delete) functionality.

---

## 🚀 Tech Stack Used

### 🎨 Frontend
- 🧱 **HTML**
- 🎨 **CSS**
- ⚛️ **React.js**

### 🛠 Backend
- 🟩 **Node.js**
- 🚂 **Express.js**
- 🍃 **MongoDB**
- 🧬 **Mongoose**

---

## 🎥 Project Features

### 🔧 CRUD Functionalities
- ➕ Create new movie entries  
- 📄 Display the list of movies  
- ✏️ Update movie details  
- ❌ Delete existing movies  

### ⭐ Additional Features
- 🎭 Upload & display **movie posters**  
- 🕵️‍♂️ **Search** movies by title  
- 📱 Fully **responsive UI**  
- ⚙️ Backend API using **Express.js**  
- 🛢 MongoDB database integration with **Mongoose**
